# Picolet 截图工具

Picolet 是用 C++20 和 Win32 API 编写的 Windows 托盘截图工具，适用于 Windows 10 22H2 和 Windows 11 x64。运行 `Picolet.exe` 后，在任务栏通知区域找到 Picolet 图标。如果图标折叠了，点击通知区域的上箭头。

单击托盘图标或按 `F1` 开始截图。画布上的白芯黑边十字以交点定位像素。框选、移动或拉伸选区时，左上角会实时显示宽和高的物理像素数。贴近屏幕顶边时，标签移到选区内侧。点「全屏」选中鼠标所在的显示器，包含任务栏，手动框选可跨屏。点「重选」可清空选区和标注，在同一冻结画面上重新框选。

| 操作 | 默认快捷键 | 结果 |
| --- | --- | --- |
| 开始截图 | `F1`（全局） | 冻结桌面并打开截图界面。 |
| 全屏 | `Ctrl+A` | 选中鼠标所在的显示器。 |
| 长截图 | `Ctrl+L` | 在当前选区中开始滚动采集。 |
| 完成并复制 | `Ctrl+C` | 将原尺寸截图复制到剪贴板并结束截图。 |
| 另存为 PNG | `Ctrl+S` | 选择保存位置；覆盖同名文件前会提示。 |
| 贴图 | `Ctrl+T` | 将截图作为独立图片窗口置顶显示。 |
| 撤销 | `Ctrl+Z` | 移除最后一笔标注。 |
| 重做 | `Ctrl+Y` | 恢复刚撤销的一笔标注。 |
| 取消 | `Esc` 或鼠标右键 | 关闭本次截图。 |

把鼠标停在选区旁的工具栏图标上，可以查看名称和快捷键。点「形状」可在参数栏选择矩形、椭圆或直线，矩形和椭圆可切换描边和实心。箭头、画笔和文字也有各自的参数栏。拖动滑块调整粗细或字号，点色块展开色板。使用键盘时，可按 `Tab` 切换控件，再用 `Enter` 激活按钮或用方向键调整滑块。

输入文字时可直接调颜色和字号，按 `Ctrl+Enter` 提交，按 `Esc` 放弃本次文字。使用「马赛克」拖动矩形时会预览分块后的实际像素，松手提交一笔。点「调整选区」可移动选区或拉动边缘。标注留在原画面的位置，调整选区只改变导出的范围。撤销后提交新标注会清除可重做的操作，重选会清空本次标注记录。

点工具栏的绿勾完成并复制，点红叉取消。复制、保存或贴图成功后结束本次截图。取消保存可回到原来的选区继续编辑。截图输出选区内的画面和已提交的标注。贴图可同时打开多张，左键拖动，滚轮以鼠标位置为中心缩放，右键关闭。图片外侧有 12 个物理像素宽的深灰渐变阴影，缩放和换屏时宽度固定。滚轮指向阴影时以最近的图片边缘为锚点。再次截图会采集桌面上实际显示的贴图及阴影。托盘菜单的「退出」会关闭程序和所有贴图。

## 长截图

先框选同一显示器、同一窗口中的滚动区域，再点击「长截图」或按 `Ctrl+L`。选区至少为 32×64 个物理像素。网页、聊天记录和文档均通过实际显示的像素采集；选区应覆盖一个连续滚动区域。进入后恢复实时画面，在选区内向下或向上滚动鼠标，旁侧预览会显示累计尺寸和当前采集位置。往返经过已经截取的内容不会重复添加，滚动到新的范围才会补充顶部或底部。

手动模式支持不停顿的滚轮和触摸板惯性滚动，也可加速或突然反向。后台以每秒 60 帧为目标连续捕获，通过中间帧连接内容，不需要每次滚动后停住；实际采集频率取决于选区大小和机器负载。滚轮和触摸板输入直接作用于原窗口，保留原来的滚动手感。预览最多每秒更新 10 次，累计尺寸和采集位置独立更新。

起步位移不足 24 个物理像素时，程序先保留首帧并提示继续滚动，避免把正文空白或重复字形当成固定栏；累计位移足够后再追加。首次识别完成后，小位移也会持续跟踪。

浮窗可选择「向下」或「向上」，再点击「自动滚动」。自动模式会把鼠标移到选区中心，逐次滚动并等待后台确认本次位移；移出选区、操作鼠标或键盘、切换窗口时暂停。连续三次没有产生位移时会提示可能已到达边界，可反向继续或完成。也可按空格切换自动滚动，按 `Enter` 完成，按配置的取消键（默认 `Esc`）或在选区内右键返回普通截图。原窗口的滚动位置保留在最后浏览的位置。

程序会结合正文位移和静止区域识别连续的固定顶部、底部，让标题栏和底部输入区在最终长图中各保留首帧的一份。单帧无法定位时先显示「正在连续跟踪」，利用缓存恢复；持续 500 毫秒仍无法连接时提示缓慢反向滚回重叠位置补截。正文候选重叠至少约 8%，且不少于 24 像素，小重叠需通过唯一性及分块像素校验。完全相同的重复段落、大片空白和大面积动画仍可能无法确定位置；真正跳过整屏、内容未被任何帧记录时无法补出缺失部分，已有可靠结果会保留。移动、缩放或最小化原窗口，以及改变显示配置，会停止采集，已有结果仍可完成或取消。自动滚动无法操作某些权限较高的窗口时，可改为手动滚动。

点击「完成」后，程序会确认最后一帧并打开独立的长图编辑窗口。「移动视图」工具可拖动图片，滚轮纵向浏览，`Shift+滚轮` 横向浏览，`Ctrl+滚轮` 以鼠标位置为中心缩放（5%～400%）。右侧提供「适应宽度」、「100%」及可点击定位的缩略图。形状、箭头、画笔、文字、马赛克和撤销、重做沿用普通截图的操作，线宽和字号始终按原图片像素计算。文字输入期间先提交文字再改变视口，中文输入法组合期间暂不改变视口。

进入长截图前的标注会随首帧正文映射到长图中。跨越固定头尾的同一笔标注仍可一次撤销，重做分支也会保留。复制、另存为 PNG 和贴图均输出完整原尺寸长图；取消保存或输出失败后可在编辑窗口继续操作。采集结果上限为 256 MiB BGRA 像素数据和 65,535 像素高度，达到上限后可完成当前结果。关闭长图编辑窗口结束本次截图。

## 设置与开机自启动

右键托盘图标打开「设置」。在「通用」区域勾选「开机自启动」并点击「保存」，Picolet 就会在当前 Windows 用户登录后启动并驻留托盘；默认关闭，无需管理员权限。取消勾选后保存即可关闭，点击「取消」或关闭设置窗口会丢弃未保存的修改。关闭程序不会取消已经保存的自启动设置。

开关反映当前用户的 Picolet 启动项是否已注册。如果已在 Windows「启动应用」中禁用 Picolet，需要在系统设置中重新启用；程序不会自动改写系统的审批状态。移动程序后，运行新位置的 `Picolet.exe`，保持自启动勾选并保存，以更新启动路径。启动命令过长或注册表不可写时会显示中文错误并保留设置窗口。快捷键保存失败时会恢复原启动项；恢复失败则显示实际读取的状态及错误，供重新检查。

点击快捷键对应的按键条目直接录入，支持单键及 `Ctrl`、`Alt`、`Shift`、`Win` 组合，可清除或恢复默认。「恢复快捷键默认」只影响快捷键。同一组不能重复，全局键可与截图内键相同。保存后立即生效。系统保留或已被占用的全局键无法注册，托盘仍能开始截图。系统拦截的按键也可能无法用于截图内命令。升级会保留已保存的快捷键，如果 `Ctrl+Y` 已分配给其他截图内操作，「重做」初始留空；如果 `Ctrl+L` 已分配给其他截图内操作，「长截图」初始留空。已明确清除的已有命令不会在升级时重新启用。更早版本中保存的旧选区键会成为统一截图键。

## 构建

需要 CMake 3.20 或以上，以及支持 C++20 的 Windows x64 工具链。下面的命令在 PowerShell 中运行。

使用 Visual Studio 2022 的 C++ 生成工具和 Windows SDK。

```powershell
cmake -S . -B build-msvc -G "Visual Studio 17 2022" -A x64
cmake --build build-msvc --config Release
ctest --test-dir build-msvc -C Release --output-on-failure
```

可执行文件位于 `build-msvc\Release\Picolet.exe`。

使用 MinGW-w64 时，确保 `g++`、`windres` 和 `mingw32-make` 都在 `PATH` 中。

```powershell
cmake -S . -B build-mingw -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build-mingw
ctest --test-dir build-mingw --output-on-failure
```

可执行文件位于 `build-mingw\Picolet.exe`。两种构建的可执行文件都只依赖 Windows 自带的 DLL，可以直接运行。

如果使用 CLion 2026.2 自带的 MinGW，遇到默认 C 运行库的静态链接错误，可在 CMake 配置中加上 `-DCMAKE_CXX_FLAGS=-mcrtdll=ucrtbase`。

## 实现与验证

普通截图、长图编辑器和采集预览浮窗使用可复用的 GDI 双缓冲，把背景、图片和界面元素合成后一次显示。长图滚动只刷新画布和缩略图定位框；缩放时额外刷新缩放文字。纯视图移动不重排工具栏或重建缩略图缓存，尺寸标签及采集提示在显示内容不变时跳过更新。绘制回归测试和超长图交互夹具见[界面绘制验证](docs/界面绘制验证.md)。采集排除失败且浮窗遮挡选区时，仍保留取帧期间临时隐藏浮窗的兼容行为。

捕获使用 GDI `BitBlt`，以物理像素把各屏幕放进同一张 BGRA 位图，屏幕间空隙填黑。标注按提交顺序合成，遮罩和输出从同一份标注像素裁剪。剪贴板使用 `CF_DIB`，PNG 由 WIC 编码后从同目录临时文件移入目标路径。快捷键设置作为整组保存在当前用户的 `HKEY_CURRENT_USER\Software\Picolet\Screenshot` 下。

自启动使用当前用户 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `Picolet` 值，命令为 `"程序完整路径" --autostart`；不另存一个可能与系统启动项失配的开关。登录启动遇到已有实例时静默退出；托盘未就绪时通过窗口计时器每秒重试，最多等待 30 秒。测试隔离方式及实际验证记录见[开机自启动验证](docs/开机自启动验证.md)。

长截图使用独立采集线程和拼接线程，界面线程只处理输入与绘制。采集线程独占并复用屏幕 DC、DIB，以高精度可等待计时器调度；队列按会话、序号和采集时间保留画面，最多 12 帧、128 MiB，满时保留旧帧并记录采样间断。必要的采集、确认工作缓冲及最终图片单独计入内存。浮窗优先通过 Windows 采集排除接口避免进入图像；不支持排除且浮窗与选区相交时，由界面线程协调临时隐藏，采集目标降为每秒 30 帧。

定位先用行指纹投票筛选位移，再做像素精修、分块校验和相邻运动帧确认，保留最近六个已定位参考帧；低频全范围搜索用于恢复。预览由后台生成不可变快照，按行二分定位条带。完成请求会停止自动输入、补取尾帧、排空队列并生成完整原图；取消会唤醒等待并在线程退出后释放资源。接口及验证步骤见[快速滚动验证文档](docs/快速滚动验证.md)。

自动测试覆盖负坐标裁剪和调整、马赛克预览与提交的像素一致性、直线及实心形状、撤销与重做、贴图阴影的透明度与主体像素、快捷键迁移和冲突、PNG 像素、中文路径与同名覆盖。长截图测试使用逐像素参考图验证双向补图、重复范围、固定头尾、无法匹配及大小限制、跨固定区标注和马赛克迁移、视口坐标及 32 位滚动范围，并模拟文档文字、聊天气泡和网页卡片排版，验证高度超过 32,767 的 PNG 往返像素。

快速滚动测试额外覆盖带时间序列的连续运动、加速和反向、重复文字整行位移、暂时撕裂、500 毫秒缺口恢复、约 10% 重叠、过期候选、队列溢出、反复启动和取消，以及大小上限后的可靠结果保留。性能基准可在 Release 构建后单独运行 `picolet_fast_scroll_tests.exe --benchmark`，记录 900×1000 合成画面连续 120 次定位提交的 P50、P95 和最大耗时。

交互验证可用浅色和深色背景查看光标及贴图阴影，在不同缩放比例的双屏上检查实时尺寸、跨屏框选和屏幕边缘的布局，并测试贴图移动、缩放及再次截图。长截图应在浏览器、聊天窗口和文档窗口中分别检查手动往返、上下自动滚动、边界暂停、取消后恢复标注、最后一帧确认、浮窗位于选区内时不混入输出，以及缩放后标注与导出的像素位置。
