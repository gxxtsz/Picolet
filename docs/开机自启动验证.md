# 开机自启动验证

## 行为与实现约定

- 托盘菜单「设置」同时管理通用选项和快捷键。自启动默认关闭，仅在点击「保存」时写入；取消、关闭窗口及「恢复快捷键默认」不提交自启动草稿。
- 自启动登记在当前用户 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `Picolet` 值中，类型为 `REG_SZ`，内容为 `"程序完整路径" --autostart`。仅管理这一值，关闭时不删除整个键或其他程序的值。
- 完整命令不超过 260 个 UTF-16 代码单元，不含结尾零。路径带引号，不依赖当前目录；超长时返回错误，不能截断。Run 在用户登录时执行，执行时间可能由系统延后，依据[微软 Run 启动项说明](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)。
- 开关显示启动项是否存在，不读取或修改未公开的系统启动审批数据。系统「启动应用」中的禁用由用户在系统设置中管理。程序普通启动和打开设置均不会重写启动项。
- 保存前验证快捷键，只提交变更项目；保存自启动后才提交变更的快捷键。快捷键提交失败时精确恢复启动项原始类型、字节或不存在状态。回滚失败必须保留窗口、重新查询实际状态并显示错误。不可读取自启动时禁用开关，仍允许保存快捷键。
- `StartupRegistration` 借用根键和子键字符串，每次操作自行释放打开的子键。内部测试可传隔离根键，错误使用 `HRESULT_FROM_WIN32` 保留；查询失败不覆盖调用者原有输出。
- `--autostart` 按完整命令行参数精确识别。重复实例静默退出；正常手动重复启动仍显示现有提示。首次注册托盘失败后每秒重试，30 秒超时退出；成功、超时及窗口销毁均停止计时器。快捷键只在托盘首次就绪后加载一次。

## 自动验证

```powershell
cmake --build build-fast-msvc --config Release
ctest --test-dir build-fast-msvc -C Release --output-on-failure
cmake --build build-plan-mingw
ctest --test-dir build-plan-mingw --output-on-failure
```

新增 `picolet.startup` 测试，在测试进程内把预定义 `HKCU` 重定向到唯一的临时子键。启动项、快捷键及权限失败场景都在该子树中执行，退出时恢复映射并删除临时子树；测试还比较真实启动项前后的原始快照。测试不会修改真实 Run 值、Windows 启动审批或用户保存的快捷键。

覆盖内容：

- 中文、空格及 UNC 路径，命令行精确匹配、260 字符边界与超长拒绝。
- 不存在状态、重复开启/关闭、移动路径更新、跳过无变化写入、无关注册表值保留及原始类型/字节恢复。
- 无效句柄、临时键真实拒绝写入产生的 `ERROR_ACCESS_DENIED`，以及自启动写入失败时不提交快捷键。
- 快捷键冲突先验证、两类设置一起提交、快捷键失败回滚和回滚再次被拒绝；确认失败后仍能查询实际启动项。
- 真实资源对话框的复选框草稿、保存、取消、标题栏关闭、恢复快捷键默认，以及读取失败后继续保存快捷键、保存失败保留窗口和草稿。
- 未改动自启动时跳过其后续故障；保持勾选保存可更新旧路径；重新加载快捷键确认配置实际落盘。
- 托盘计时器的延迟成功、30 秒边界、超时、重新启动、停止后的迟到消息，以及成功/超时/析构不遗留计时器。
- 对实际构建出的 `Picolet.exe` 创建重复 `--autostart` 进程，确认在已有互斥体时迅速以成功状态退出。

## 交互夹具与人工登录验收

运行 `build-fast-msvc\Release\picolet_settings_fixture.exe` 可打开与正式版本相同的设置窗口。此夹具在独立进程内隔离 HKCU，保存只影响临时配置，关闭后自动清理。夹具的全局截图键初始为空，避免注册用户当前的按键。

1. 检查「通用」和两组快捷键、说明、保存/取消按钮完整显示，使用鼠标及 Tab/空格操作复选框。
2. 勾选自启动，修改快捷键，再取消或关闭窗口；自动测试会复核全部草稿未写入。
3. 点击「恢复快捷键默认」，确认复选框不受影响。若正式 Picolet 正占用 F1，尝试一起保存应显示占用提示、保留草稿，并恢复临时启动项；清除夹具中的全局键后可重新保存。
4. 在正式程序的设置中自行开启自启动并保存，然后注销并重新登录。确认 Picolet 驻留托盘、没有自动开始截图；手动再次启动仍有提示，重复自启动则不弹提示。
5. 在正式程序中关闭自启动并保存，下次登录应不启动。检查 Windows「启动应用」禁用后的行为及程序内说明；移动可执行文件后，从新位置打开设置并保存，确认登记路径更新。
